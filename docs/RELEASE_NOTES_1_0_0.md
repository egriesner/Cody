# RIFT: The Bestiary Protocol - Release Notes (1.0.0)

Developer: **Code Maxx Studios**

## 1.0 Launch Highlights

- Full Android tablet gameplay loop finalized:
  - Twin-stick movement/aim controls
  - Survival + scavenging + crafting progression
  - Companion gameplay modes (Keeley / Annalize)
  - Boss-gated Titan Protocol finale (Overlord Vex)
- Major premium combat polish pass:
  - Dash afterimages and expanded impact VFX
  - Shockwave rings and cinematic screen shake events
  - Critical-hit feedback and floating hit markers
  - Near-miss projectile cues and low-health danger visuals
  - Boss shockwave telegraphs with countdown readability
- UI/UX polish for child-tablet play:
  - High-contrast, large touch-target, two-thumb layout
  - Animated menu interactions and refined button feel
  - Intro splash sequence with skip support
- Branding finalized to **Code Maxx Studios**
  - Startup studio graphic and in-game branding updates
- Audio presentation upgrade:
  - New menu theme loop
  - Studio sting on startup intro
  - In-run dynamic music intensity/ducking
  - Layered SFX playback for high-action readability
- Release process hardening:
  - Preflight guardrails for docs/workflows/assets
  - Automated CI workflows for APK/AAB and Play publish path
  - Play upload handoff + compliance templates
