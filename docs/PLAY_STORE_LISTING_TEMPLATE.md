## Full Description

Track hostile creatures, survive escalating waves, and master the Bestiary in a high-energy sci-fi world.

In **RIFT: The Bestiary Protocol**, you explore dangerous biomes, scavenge resources, craft stronger weapons, and fight through fast-paced combat built for Android tablet controls.

### Core Features

- Twin-stick combat tuned for tablet touch controls
- 3 connected biomes with different visual identities
- Survival loop: health, hunger, and recovery management
- 5-slot contextual hotbar (attack/eat/rhino overrides)
- Companion system:
  - Keeley crowd-control scream and toxic upgrade path
  - Annalize railgun support with boosted loot flow
- Wild-card Rhino Charge burst mode
- Titan Protocol progression into Overlord Vex boss encounter
- Run scoring with combo multipliers and performance rank

### Built for Tablet Play

- Two-thumb layout
- Edge dead-zone palm rejection
- High-contrast and UI-scale accessibility settings
- Short reward loops and quick retry pacing
